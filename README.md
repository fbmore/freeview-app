# freeview-app

The FreeView site, live at https://freeview.app (GitHub Pages from `main`, behind Cloudflare).
Same structure as the Videogram site: home page with feature rows and a screenshot gallery, plus privacy,
terms, support and 404.

The pages are generated by `build.py` (all styles inline): edit it, run `python3 build.py .`, commit.
Screenshots (`shot-*.webp`) are real captures from the iPhone 17 Pro Max and iPad Pro 13" simulators in dark
mode, taken with `marketing/store/capture.py` in the FreeView repo (the demo deck in `marketing/demo-media`)
and scaled to 612 and 880 px wide with cwebp.
